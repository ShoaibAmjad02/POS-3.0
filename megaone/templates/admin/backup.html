Information

Automatic backups run every 24 hours. The backup file is stored at:
deployment/backups/{{ company_name|slugify }}.sql

Each new backup replaces the previous one. No timestamped copies are kept.

To schedule automatic backups, run:
python manage.py auto_backup
via Windows Task Scheduler every hour (the command checks if 24h have passed).

To force an immediate backup:
python manage.py auto_backup --force
